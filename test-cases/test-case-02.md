# Тест-кейс: Отправка формы заявки с пустым полем "Имя"

## ID

TC-002

## Название

Отправка формы заявки с пустым обязательным полем "Имя"

## Приоритет

Medium

## Предусловие

Сайт TestShop открыт. Пользователь находится в разделе "Контакты".

## Тестовые данные

- Имя: (пусто)
- Телефон: +7 (987) 654-32-10
- Email: test@test.ru
- Продукция: Зерновые культуры
- Сообщение: (пусто)

## Шаги

1. Открыть раздел "Контакты"
2. Оставить поле "Ваше имя" пустым
3. Заполнить поле "Телефон": +7 (987) 654-32-10
4. Заполнить поле "Email": test@test.ru
5. Заполнить поле "Интересующая продукция": Зерновые культуры
6. Нажать кнопку "Отправить заявку"

## Ожидаемый результат

Форма не отправляется. Браузер показывает сообщение "Заполните это поле" под полем "Ваше имя". Фокус переходит на пустое поле.

## Постусловие

Форма остаётся заполненной (кроме поля "Имя").

## Связь с багом

Не применимо
