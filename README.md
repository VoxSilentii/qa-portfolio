# Портфолио QA
Начинающий тестировщик. Здесь собраны примеры моих работ: баг-репорты, чек-листы, тест-кейсы, результаты исследований реальных сайтов.

## О проекте
В портфолио представлены два направления:
1. **Учебные проекты (Education)**: тестирование локальной версии сайта (TestShop). Упор сделан на функциональное тестирование, UI, API и написание тестовой документации.
2. **Реальные сайты**: исследование доступных интерфейсов. Тестирование форм и поиск багов верстки.
