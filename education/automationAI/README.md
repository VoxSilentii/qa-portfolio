# Автотесты с использованием AI (Playwright)

В этой папке собраны мои практические наработки по автоматизации тестирования (E2E). 
Проект создан для отработки навыков написания тестов с использованием AI-инструментов (DeepSeek, Claude).

## Что проверяют тесты:
- `swaglabs.spec.js` — авторизация на сайте SwagLabs и добавление товара в корзину.
- `checkout.spec.js` — полный флоу оформления заказа (добавление двух товаров, заполнение данных покупателя, подтверждение заказа).

## Стек:
JavaScript, Playwright, AI-генерация кода.
