# Баг-репорт: Изображение третьего слайда в разделе "Доставка" не отображается
## Окружение

- Устройство: PC
- ОС: Windows 11
- Браузер: Microsoft Edge (Версия 155.0.4283.45)
- Разрешение: 2560 x 1440
- Как воспроизведено: открыл сайт TestShop в браузере Microsoft Edge

## Предусловие

Сайт TestShop открыт

## Шаги воспроизведения

1. Перейти к разделу "Доставка"
2. Пролистать к 3 слайду
3. Посмотреть на изображение

## Ожидаемый результат

Отображается фотография самосвала.

## Фактический результат

Фотография не отображается. На её месте заглушка. 

## Severity

Minor

## Priority

Medium
