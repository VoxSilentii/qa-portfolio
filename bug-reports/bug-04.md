# Баг-репорт: Кнопка "Оставить заявку" налезает на заголовок "О компании" на iPhone SE
## Окружение

- Устройство: iPhone SE - эмуляция в DevTools
- ОС: Windows 11
- Браузер: Microsoft Edge (эмуляция iPhone SE)
- Как воспроизведено: DevTools -> iPhone SE (375×667)

## Предусловие

Сайт TestShop открыт

## Шаги воспроизведения

1. Открыть DevTools (F12)
2. Включить режим устройства (Ctrl+Shift+M)
3. Выбрать iPhone SE (375×667)

## Ожидаемый результат

Кнопка "Оставить заявку" и заголовок "О компании" не пересекаются

## Фактический результат

Кнопка "Оставить заявку" соприкасается с заголовком "О компании", текст перекрывается
