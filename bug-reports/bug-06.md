# Баг-репорт: На мобильных устройствах отсутствует бургер-меню навигации

## Окружение

- Устройство: iPhone SE (375x667) - эмуляция в DevTools
- ОС: Windows 11
- Браузер: Microsoft Edge (эмуляция)
- Как воспроизведено: DevTools -> iPhone SE (375x667)

## Предусловие

Сайт TestShop открыт

## Шаги воспроизведения

1. Открыть DevTools (F12)
2. Включить режим устройства (Ctrl+Shift+M)
3. Выбрать iPhone SE (375x667)
4. Посмотреть на шапку сайта

## Ожидаемый результат

Отображается бургер-меню (иконка с тремя полосками) для навигации по разделам. Меню свёрнуто, не занимает весь экран.

## Фактический результат

Бургер-меню отсутствует. Пункты меню переносятся на несколько строк и занимают пол-экрана.
