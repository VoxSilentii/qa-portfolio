# Баг-репорт: Видео в баннере не отображается на ширине меньше 768px
## Окружение

- Устройство: iPhone SE (375×667) и iPhone 16 Pro Max (956×440) — эмуляция в DevTools
- ОС: Windows 11
- Браузер: Microsoft Edge (эмуляция iPhone SE)
- Как воспроизведено: DevTools -> iPhone SE (375x667) -> iPhone 16 Pro Max (956x440)

## Предусловие

Сайт TestShop открыт

## Шаги воспроизведения

1. Открыть DevTools (F12)
2. Включить режим устройства (Ctrl+Shift+M)
3. Выбрать iPhone SE (375×667)
4. Посмотреть на баннер с видео

## Ожидаемый результат

Отображается видео в баннере

## Фактический результат

Видео не загружается. На месте видео - чёрный фон. На ширине 768px и меньше видео не отображается. На ширине 769px и больше видео работает корректно.

## Severity

Major

## Priority

High
