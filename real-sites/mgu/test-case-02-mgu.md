# Тест-кейс: Проверка защиты от XSS в поисковой строке

## ID

TC-002

## Название

Проверка экранирования HTML/JS-тегов в поисковой строке сайта МГУ.

## Предусловие

Сайт МГУ открыт.

## Шаги

1. Ввести в поисковую строку `<script>alert(1)</script>`
2. Нажать Enter (или кнопку поиска)
3. Посмотреть на результат и консоль браузера

## Ожидаемый результат

Скрипт не выполняется (всплывающее окно alert не появляется). Сайт обрабатывает запрос как обычный текст и выводит сообщение «Ничего не найдено».

## Результат выполнения

Тест пройден. Сайт корректно обработал запрос, скрипт не выполнился, ошибок в консоли нет.
