# Тест-кейс: Проверка граничных значений поля "Сумма для пополнения"

## ID

TC-001

## Название

Проверка ввода длинного числового значения в поле "Сумма для пополнения" и отсутствие поломки верстки.

## Предусловие

Открыта страница с акцией "Увеличиваем бюджет до 30 000".

## Шаги

1. Перейти на страницу акции.
2. Установить курсор в поле "Сумма для пополнения".
3. Ввести число, состоящее из 13 и более символов.
4. Посмотреть на интерфейс страницы.

## Ожидаемый результат

1. Поле ввода имеет ограничение и не позволяет ввести больше символов, чем помещается в интерфейс.
2. Введенное значение не выходит за границы поля ввода.
3. Блок с результатом ("Итого поступит на счёт") сохраняет свою позицию и размеры, текст не наезжает на другие элементы.
