# Баг-репорт: Переполнение и наезд текста блока "Итого поступит на счёт" при вводе длинного числового значения

## Окружение

- Устройство: PC
- ОС: Windows 11
- Браузер: Microsoft Edge (Версия 155.0.4283.62)
- Разрешение: 2560 × 1440

## Предусловие

Открыта страница с акцией "Увеличиваем бюджет до 30 000".

## Шаги воспроизведения

1. Перейти на страницу акции.
2. Установить курсор в поле "Сумма для пополнения".
3. Ввести число, состоящее из 13 и более символов.
4. Посмотреть на правую часть экрана в блок "Итого поступит на счёт".

## Ожидаемый результат

1. Введенное значение корректно обрабатывается.
2. Блок с результатом ("Итого поступит на счёт") сохраняет свою позицию и размеры.
3. Текст с итоговой суммой не выходит за пределы своей плашки.

## Фактический результат

При вводе длинного числа итоговая сумма отображается огромным шрифтом. Текст ("1234567891234") выходит за границы правого блока. Верстка ломается.

## Severity

Major

## Priority

Medium
