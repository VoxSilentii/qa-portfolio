# Баг-репорт: Ошибка 403 Forbidden при клике на логотип Яндекс.Метрики во встроенном виджете
## Окружение

- Устройство: PC
- ОС: Windows 11
- Браузер: Microsoft Edge (Версия 156.0.4314.42)
- Разрешение: 2560 × 1440

## Предусловие

Открыта главная страница

## Шаги воспроизведения

1. Открыть главную страницу.
2. Пролистать страницу в самый низ к футеру.
3. Кликнуть на виджет со статистикой Яндекс.Метрики.
4. В открывшемся окне с графиком кликнуть на надпись "Яндекс.Метрика".
   
## Ожидаемый результат

Пользователь перенаправляется на главную страницу сервиса Яндекс.Метрика или на публичную страницу статистики сайта. Ошибки доступа не возникает. (Либо ссылка неактивна, если доступ к личному кабинету закрыт).

## Фактический результат

Открывается страница с ошибкой "403 Доступ запрещён" (Forbidden). Пользователь видит страницу с ошибкой, так как у него нет прав доступа к личному кабинету статистики сайта.
