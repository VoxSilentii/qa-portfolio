# Баг-репорт: Ошибка отображения разделительной полосы на главной странице

## Окружение

- Устройство: PC
- ОС: Windows 11
- Браузер: Microsoft Edge (Версия 156.0.4314.42)
- Разрешение: 2560 × 1440

## Предусловие

Открыта главная страница

## Шаги воспроизведения

1. Открыть главную страницу
2. Установить масштаб страницы 100%
3. Обратить внимание на линию подчеркивания активной вкладки в верхнем меню
4. (Опционально) Изменить масштаб до 90%, чтобы увидеть разницу.

## Ожидаемый результат

Разделительная полоса (линия подчеркивания) цельная, ровная, без разрывов.

## Фактический результат

При масштабе 100% линия подчеркивания разрывается на отдельные фрагменты. При масштабе 90% дефект исчезает.
