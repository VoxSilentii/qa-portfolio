# Баг-репорт: Нарушение верстки UI после обновления библиотеки egui (наложение элементов)

## Окружение

- Устройство: PC
- ОС: Windows 10/11
- Приложение: Endless Dream (Rust)
- Версия ПО: Build после обновления библиотеки (egui 0.34)

## Предусловие

Приложение запущено. Окно плеера находится в оконном режиме.

## Шаги воспроизведения

1. Запустить приложение Endless Dream (сборка после обновления egui до 0.34).
2. Обратить внимание на левую панель (меню) и правую часть (плейлист).
3. Оценить расположение текста "Rust Player", кнопок управления и надписи "Плейлист пуст".

## Ожидаемый результат

Элементы интерфейса (текст, кнопки, ползунки) располагаются корректно, не перекрывая друг друга. Верстка соответствует макету.

## Фактический результат

После обновления библиотеки `egui` с версии 0.27 до 0.34 произошло нарушение верстки: элементы интерфейса дублируются и наезжают друг на друга.
