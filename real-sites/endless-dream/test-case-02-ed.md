# Тест-кейс: Переключение треков во время воспроизведения

## ID

TC-002

## Название

Переключение на следующий и предыдущий трек во время воспроизведения.

## Предусловие

Приложение Endless Dream запущено. В плейлисте минимум 2 трека. Первый трек воспроизводится.

## Тестовые данные

Плейлист из 2+ треков.

## Шаги

1. Нажать кнопку "Следующий трек".
2. Убедиться, что начал играть второй трек.
3. Нажать кнопку "Предыдущий трек".
4. Убедиться, что начал играть первый трек.

## Ожидаемый результат

1. Воспроизведение переключается на следующий трек в списке.
2. Название в нижней панели меняется на название второго трека.
3. При нажатии "Предыдущий" воспроизведение возвращается к первому треку.
4. Воспроизведение не прерывается и не выдает ошибок.
