# Тест-кейс: Попытка добавления невалидного файла (не аудио)

## ID

TC-005

## Название

Попытка добавления файла с неподдерживаемым расширением (txt/pdf) в плейлист.

## Предусловие

Приложение запущено. Плейлист пуст.

## Тестовые данные

Файл `document.txt` (обычный текстовый файл).

## Шаги

1. Нажать кнопку "Добавить файлы".
2. В системном диалоге выбрать файл `document.txt` и подтвердить выбор.
3. Дождаться реакции интерфейса.

## Ожидаемый результат

1. Файл не добавляется в плейлист.
2. Счетчик "Треков в плейлисте" не меняется.
3. Приложение не зависает и не вылетает с ошибкой.
