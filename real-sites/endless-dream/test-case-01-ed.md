# Тест-кейс: Успешное добавление папки с музыкальными файлами

## ID

TC-001

## Название

Успешное добавление папки с музыкальными файлами в плейлист.

## Предусловие

Приложение Endless Dream запущено. Плейлист пуст.

## Тестовые данные

Папка `C:\Music\TestFolder`, содержащая 3 валидных аудиофайла (mp3).

## Шаги

1. Нажать кнопку "Выбрать папку".
2. В системном диалоге выбрать папку `TestFolder` и подтвердить выбор.
3. Дождаться завершения сканирования.

## Ожидаемый результат

1. Треки из папки успешно добавляются в плейлист.
2. Счетчик "Треков в плейлисте" увеличивается на 3.
3. В списке отображаются корректные названия треков и обложки (если есть).
4. Приложение не зависает и не выдает ошибок.
