# Endless Dream (Pet-проект)

Легкий десктопный музыкальный плеер, написанный на Rust. 

**Роль:** Разработчик, QA Engineer (исследовательское тестирование).
**Стек:** Rust, egui 0.34, Windows, GitHub Issues.

## Что было протестировано
- Добавление папок и отдельных файлов.
- Управление воспроизведением (Play/Pause, Next/Prev, Громкость).
- UI/UX и адаптивность при изменении масштаба.
- Обработка невалидных файлов (txt/pdf).
- Чтение метаданных.
- Производительность (потребление ЦП в простое и в трее).
