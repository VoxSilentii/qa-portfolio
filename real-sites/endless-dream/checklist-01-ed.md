# Чек-лист: Базовый функционал музыкального плеера Endless Dream

## Отображение

- [ ] Приложение запускается без ошибок
- [ ] Окно приложения открывается в корректном размере
- [ ] Левая панель с кнопками "Выбрать папку" и "Добавить файлы" отображается
- [ ] Счетчик "Треков в плейлисте" отображается
- [ ] Нижняя панель управления (Play, Пауза, Переключение, Громкость) отображается
- [ ] При пустом плейлисте отображается заглушка "Нет воспроизводимого трека"

## Позитивные сценарии

- [ ] Выбрать папку с 3 валидными mp3 -> треки добавляются в плейлист
- [ ] Выбрать папку с 10 треками -> счетчик "Треков в плейлисте" показывает 10
- [ ] Добавить одиночный валидный файл -> трек появляется в списке
- [ ] Нажать Play при выбранном треке -> воспроизведение начинается
- [ ] Нажать Паузу во время воспроизведения -> воспроизведение останавливается
- [ ] Нажать "Следующий трек" -> включается следующий трек в списке
- [ ] Нажать "Предыдущий трек" -> включается предыдущий трек
- [ ] Переместить ползунок громкости влево -> звук становится тише
- [ ] Переместить ползунок громкости вправо -> звук становится громче
- [ ] Удалить трек из плейлиста (не играющий) -> трек исчезает из списка, счетчик уменьшается

## Негативные сценарии

- [ ] Выбрать пустую папку -> плейлист не меняется, счетчик не меняется
- [ ] Выбрать файл `.txt` -> файл не добавляется в плейлист
- [ ] Выбрать файл `.pdf` -> файл не добавляется в плейлист
- [ ] Удалить играющий трек -> воспроизведение останавливается, трек исчезает из списка
- [ ] После удаления играющего трека нажать Play -> удаленный трек не воспроизводится (воспроизводится первый из оставшихся, если они есть)

## Отображение метаданных

- [ ] Трек с латинским названием отображается корректно
- [ ] Трек с кириллическим названием (UTF-8) отображается корректно
- [ ] Трек с кириллическим названием (CP1251) отображается корректно (без mojibake)
- [ ] Трек с обложкой -> обложка отображается
- [ ] Трек без обложки -> отображается плейсхолдер (заглушка)
- [ ] Длинное название трека не ломает верстку (обрезается или переносится)

## UI/UX и адаптивность

- [ ] При изменении размера окна элементы не уезжают за границы
- [ ] При масштабировании (Ctrl + колесико) колонки не уходят за экран
- [ ] Текст "Громкость" не наезжает на кнопки управления
- [ ] Кнопки Play/Пауза визуально различимы (активное/неактивное состояние)
- [ ] Элементы интерфейса не дублируются и не наезжают друг на друга после обновления egui (версия 0.34)

## Производительность

- [ ] В состоянии простоя (трек на паузе) потребление ЦП не превышает 1-2%
- [ ] В состоянии простоя (в трее) потребление ЦП не превышает 1-2%
- [ ] Потребление ОЗУ в простое не превышает 50 МБ
- [ ] Приложение не вызывает сильного нагрева устройства в фоне
