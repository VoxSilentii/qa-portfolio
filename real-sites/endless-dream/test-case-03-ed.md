# Тест-кейс: Изменение уровня громкости во время воспроизведения

## ID

TC-003

## Название

Изменение уровня громкости ползунком во время воспроизведения трека.

## Предусловие

Приложение запущено. В плейлисте есть минимум один трек. Трек воспроизводится. Ползунок громкости находится в среднем положении.

## Тестовые данные

Не требуются.

## Шаги

1. Переместить ползунок громкости в крайнее левое положение (0%).
2. Переместить ползунок громкости в крайнее правое положение (100%).
3. Переместить ползунок громкости в среднее положение (50%).

## Ожидаемый результат

1. При перемещении влево (0%) звук полностью пропадает.
2. При перемещении вправо (100%) громкость звука увеличивается до максимума.
3. Уровень звука меняется плавно, без щелчков и резких скачков.
4. Приложение не зависает, воспроизведение не прерывается.
