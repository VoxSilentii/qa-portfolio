# Баг-репорт: Ошибка JavaScript BX.setJSList is not a function при переходе в раздел «Документы» на сайте МГУ

## Окружение

- Устройство: PC
- ОС: Windows 11
- Браузер: Microsoft Edge (Версия 155.0.4283.62)
- Разрешение: 2560 × 1440

## Предусловие

Сайт МГУ открыт. Открыта консоль разработчика (F12) и очищена от старых записей.

## Шаги воспроизведения

1. Открыть DevTools (F12) и перейти на вкладку консоль
2. В верхнем меню навести мышь на кнопку "Университет"
3. В выпадающем меню нажать на кнопку "Документы" 
4. Посмотреть на вкладку Console

## Ожидаемый результат

1. Происходит корректный переход на страницу «Документы».
2. В консоли разработчика нет ошибок (красных сообщений). Скрипты выполняются без сбоев.

## Фактический результат

Переход в раздел выполняется, но в консоли возникает ошибка: 'Uncaught TypeError: BX.setJSList is not a function'. Выполнение JS-скрипта прерывается.

Minor
