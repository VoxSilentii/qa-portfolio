# Чек-лист: Форма заявки (статическая)

## Отображение

- [ ] Форма отображается в разделе "Контакты"
- [ ] Все поля видны: имя, телефон, email, продукция, сообщение
- [ ] Кнопка "Отправить заявку" отображается
- [ ] Заголовок "Оставьте заявку" виден

## Позитивные сценарии

- [ ] Заполнить все поля корректно -> кнопка "Отправить заявку" активна
- [ ] Поля принимают корректные данные
- [ ] Валидация HTML5 работает (required)

## Негативные сценарии

- [ ] Пустое поле "Имя" -> ошибка браузера "Заполните это поле"
- [ ] Пустое поле "Телефон" -> ошибка браузера "Заполните это поле"
- [ ] Пустое поле "Email" -> ошибка браузера "Заполните это поле"
- [ ] Пустое поле "Продукция" -> ошибка браузера "Заполните это поле"
- [ ] Неверный email (без @) -> ошибка браузера
- [ ] Неверный телефон (буквы) -> ошибка или принимает

## Граничные значения

- [ ] Имя: 1 символ -> поле принимает значение (или ошибка, если задан minlength)
- [ ] Имя: 2 символа -> поле принимает значение
- [ ] Имя: 50 символов -> поле принимает значение
- [ ] Имя: 100 символов -> поле принимает значение (или ошибка, если задан maxlength)
- [ ] Сообщение: пустое -> отправка проходит (необязательное)
- [ ] Сообщение: 500 символов -> поле принимает значение

## Спецсимволы

- [ ] Ввод `<script>alert(1)</script>` -> не выполняется (XSS)
- [ ] Ввод эмодзи -> ok или ошибка
- [ ] Ввод кириллицы в email -> ошибка
- [ ] Ввод пробелов -> обрезаются или ошибка

## UI/UX

- [ ] Поля подсвечиваются при ошибке (браузер)
- [ ] Сообщение об ошибке понятное
- [ ] Кнопка активна, когда поля заполнены

## Адаптивность

- [ ] 1920px - форма отображается корректно
- [ ] 768px - форма отображается корректно
- [ ] 375px - форма отображается корректно
- [ ] На мобилке поля не вылезают за экран
