# Чек-лист: Форма заявки

## Отображение

- [ ] Форма отображается в разделе "Контакты"
- [ ] Все поля видны: имя, телефон, email, продукция, сообщение
- [ ] Кнопка "Отправить заявку" отображается
- [ ] Заголовок "Оставьте заявку" виден

## Позитивные сценарии

- [ ] Заполнить все поля корректно -> форма отправляется
- [ ] После отправки показывается сообщение об успехе
- [ ] Данные приходят на email получателя

## Негативные сценарии

- [ ] Пустое поле "Имя" -> ошибка "Заполните поле"
- [ ] Пустое поле "Телефон" -> ошибка "Заполните поле"
- [ ] Пустое поле "Email" -> ошибка "Заполните поле"
- [ ] Пустое поле "Продукция" -> ошибка "Заполните поле"
- [ ] Неверный email (без @) -> ошибка
- [ ] Неверный телефон (буквы) -> ошибка

## Граничные значения

- [ ] Имя: 1 символ -> ok или ошибка
- [ ] Имя: 2 символа -> ok
- [ ] Имя: 50 символов -> ok
- [ ] Имя: 100 символов -> ошибка
- [ ] Сообщение: пустое -> ok (необязательное)
- [ ] Сообщение: 500 символов -> ok

## Спецсимволы

- [ ] Ввод `<script>alert(1)</script>` -> не выполняется (XSS)
- [ ] Ввод эмодзи -> ok или ошибка
- [ ] Ввод кириллицы в email -> ошибка
- [ ] Ввод пробелов -> обрезаются или ошибка

## Технические

- [ ] Двойной клик на "Отправить" -> не отправляет дважды
- [ ] Отправка при отключённом интернете -> сообщение об ошибке
- [ ] Отправка при медленном интернете -> индикатор загрузки

## UI/UX

- [ ] Поля подсвечиваются при ошибке
- [ ] Сообщение об ошибке понятное
- [ ] Кнопка активна, когда поля заполнены

## Адаптивность

- [ ] 1920px - форма отображается корректно
- [ ] 768px - форма отображается корректно
- [ ] 375px - форма отображается корректно
- [ ] На мобилке поля не вылезают за экран
