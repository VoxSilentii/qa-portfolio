# Чек-лист: Слайдер в разделе "Доставка"

## Отображение

- [ ] Слайдер отображается
- [ ] Все слайды видны по одному
- [ ] Изображения загружаются
- [ ] Подписи к слайдам отображаются
- [ ] Кнопки влево/вправо видны
- [ ] Точки навигации видны

## Функционал

- [ ] Клик "вправо" -> следующий слайд
- [ ] Клик "влево" -> предыдущий слайд
- [ ] Клик на точку -> соответствующий слайд
- [ ] Цикличность: после последнего -> первый
- [ ] Автопрокрутка работает

## Негативные сценарии

- [ ] Быстрые клики -> не ломается
- [ ] Картинка не загрузилась -> alt-текст
